## <h2 style="color:#27AE60;">✨ Features</h2>

<div style="padding: 15px; border: 1px solid #e1e1e1; border-radius: 10px; background: #fafafa;">

### 🔐 **Authentication & Users**
- JWT Authentication  
- Role-based access control  
- Token refresh  
- User profiles  

### 🏆 **LOG Module**
- House proposals  
- Draft system  
- Captain assignment  
- Match schedules & results  
- Leaderboards  

### 🎯 **Olympiad Module**
- Team registrations with fee handling  
- Multi-sport tournaments  
- Bracket management  

### 🏟️ **Court Booking**
- Real-time availability  
- Price calculations  
- Admin approval flow  

### 👥 **Team & Sports Management**
- Create teams  
- Manage rosters  
- Configure sports  

</div>

## <h2 style="color:#E67E22;">🛠 Tech Stack</h2>

### **Backend**
- Django 5.2.7  
- DRF 3.16.1  
- JWT (SimpleJWT + Djoser)  
- SQLite / MySQL  
- Python 3.11  

### **Frontend**
- Next.js 16 (App Router)  
- React 19  
- TypeScript  
- Tailwind CSS  
- Axios  
- Framer Motion
